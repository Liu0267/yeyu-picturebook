## VLM确实发现的问题

整页输入能读出本页正文，但视觉结果把正文提到的“大口袋”也列为可见物体，还给出与猫相同的框，原图中缺少清晰视觉依据。

使用去掉正文的插图裁片后，没有再列出大口袋，但把原书身份明确为猫的条纹角色识别为“老虎”。这说明仅靠模型输出格式通过，不能认为语义也已通过。

两次输出均保持needs_review，没有写进24条已核对的原书事实，也没有自动发布为可信视频证据。复核意见保存在understanding记录的review_notes。队员后续应结合原书角色ID、原图和模型观察核查；独立画面观察与原书身份结论分别保存，不能静默覆盖冲突。

## 新增可用接口

| 接口 | 用途 |
|---|---|
| `POST /v1/pages/{page_id}/understand` | 本机整页理解，返回run_id |
| `POST /v1/pages/{page_id}/understand?source_ref_id=...` | 对当前页的original_image区域单独理解 |
| `GET /v1/pages/{page_id}/understandings` | 读取草稿、格式校验状态及复核意见 |
| `POST /v1/shots/{shot_id}/narration` | 对已审核分镜独立生成旁白，不要求先有视频 |
| `GET /v1/books/{book_id}/narrations` | 获取实际WAV资产ID、时长与原文 |
| `POST /v1/clips/{clip_id}/narration` | 依据已有视频生成旁白、字幕和新媒体版本 |

插图裁片的模型原始框相对于裁片；API中的parsed框已映射回原书整页0—1坐标，并提供source_region，raw_text保持原样。页版本改变会令旧理解和旧旁白过期。

视频合成使用真实WAV时长，语音延迟200毫秒，输出WebVTT和MP4内嵌字幕。若音频长于原视频，补足末尾静止帧，并记录tail_extension_ms；该补足不能作为新增AI动态生成内容。新成片再次抽帧，旧片段/帧过期。

## 当前机器启动

双击项目根目录 `启动本地服务.command`，即可读取已经配置的 `.local/runtime.env` 并启动API和单个工作进程。

```sh
curl --noproxy '*' http://127.0.0.1:8765/v1/health
curl --noproxy '*' http://127.0.0.1:8765/v1/books/book_cat/narrations
curl --noproxy '*' http://127.0.0.1:8765/v1/pages/book_cat_p008/understandings
```

每次POST本地模型任务会实际进行推理；草稿不会自动变成已确认事实。未获准的参考图片仍不能发送至外部服务。

## 换机器部署模型

Apple Silicon、Python 3.12。模型环境与API环境分开：

```sh
mkdir -p .local
python3.12 -m venv .local/model-env
.local/model-env/bin/python -m pip install -r requirements.models.lock.txt
HF_HOME="$PWD/.local/hf-cache" .local/model-env/bin/python scripts/download_models.py --directory .local/models
```

在 `.local/runtime.env` 中设置YU_MODEL_PYTHON、YU_VLM_MODEL_DIR、YU_TTS_MODEL_DIR为相应绝对路径；视频另设YU_VIDEO_PROVIDER=agnes及私有YU_AGNES_KEY_FILE。配置示例见 `.env.example`。两个模型权重均为Apache 2.0，参见 [Qwen3-VL模型卡](https://huggingface.co/mlx-community/Qwen3-VL-4B-Instruct-4bit)、[Qwen3-TTS模型卡](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-4bit)。

视频接口根据 [Agnes当前官方文档](https://wiki.agnes-ai.com/en/docs/agnes-video-25-flash.md) 接入，没有沿用已退役的v2.0格式。
