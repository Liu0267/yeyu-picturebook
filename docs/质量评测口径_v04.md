# 质量评测口径与当前证据

## 文字

`evaluation/ocr_reference_v1.json`固定8段选定原文，每书2段，保存页ID、原图SHA256、原OCR行ID及助手对照图像转录的参照。不是随机抽样，未独立人工双校；不得外推为全书正确率。

字符错误率CER为替换、删除和插入的最小编辑距离除以参照字符数。本轮先NFKC规范化，只计汉字，忽略标点、数字与拼音。CER可以大于1，不将其强行截断成0—100%的“准确率”。Apple Vision OCR与EPUB内嵌文字提取分组报告，不能把后者的零错误当作OCR成绩。

实际结果见`evaluation/ocr_results_v1.json`：6段Apple Vision样本micro-CER约15.84%；2段内嵌文字样本CER为0。注音版两页的开发对照中，按字行高度分离汉字后，CER由约54.92%降至约1.64%，仍漏掉两个“的”。两页样本不足以宣称泛化提升；参照版本与原始识别均保留。建议文字通过独立记录提供，采纳时必须走版本化校对，不自动覆盖原文。

## 图像与采集

115个文件页做了同一组启发式质量盘点，文件页序连续；印刷页码尚未全量核对，不能因此宣布没有缺页。《海洋女神》有1处完全重复图像，6页触发暗边提示，可能由原插画深色构图造成，不等于发现6处真实遮挡。

模糊、低对比、亮色连通区域和暗边指标仅作候选提示。明确四角和旋转后生成独立副本，保留正逆像素变换。合成模糊/遮挡/透视测试仅说明工程行为，不能伪装成相机实拍泛化评测。

## 视频

真实模型调用、MP4可播放、画面没有条纹、动作可感知，是不同的验收项。旧样片虽有实际模型日志，用户指出几乎不动后，动作被判未通过并退回待审核。像素差和光流数值也不能单独证明动作质量。

所有尝试保留原始参数、输入/运行库/输出哈希、耗时与实际帧。当前针对结束关键帧与原始VAE做工程对照；要注明具体改动，不能将多项同时变化的配置称为单因素实验。原定兔子“约束开/关”配对中的旧参数控制组在启动前取消，故这组没有完整配对结果，不计算胜率或效果量。

实际视听表为`evaluation/human_audiovisual_review_blank.csv`。评分至少覆盖身份、原书事实、画风、可感知动作、连续性、语音和字幕。必须记录真实评阅者与时间码问题；当前没有真人盲评结果，不填虚构评分，不将助手自评称为真人盲评。

## 性能与费用

`evaluation/run_measurements.json`逐项保留所有非Mock任务，包括失败与取消。不同帧数、模型、提示词和配置的耗时不混算成统一性能指标。对单次观测标记n=1，不把一次生成速度当成稳定基准。

本机视频推理不调用视频云API，但硬件、电费与耗损没有测算；不能表述为总成本为零。Agnes请求的账单仍未知；内置image_gen没有报告底层模型和本次价格。离线预生成不等于B端实时生成，当前没有测得B业务交互延迟。
